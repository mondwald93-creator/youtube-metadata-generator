# 유튜브 메타데이터 자동 생성기

헬씨허브 · 지킴 유튜브 채널 전용 메타데이터 자동 생성 도구

🔗 **[라이브 데모 보러가기](#)** ← 배포 후 URL 업데이트 예정

---

## 왜 만들었나

두 채널(헬씨허브·지킴)에 영상을 업로드할 때마다 제목, 설명란, 해시태그를 매번 수동으로 작성해야 했다. 채널마다 SEO 전략이 다르고, 잘 되는 제목 패턴도 다르기 때문에 담당자의 경험과 감에 의존하는 작업이었다.

이 도구는 영상 음성을 텍스트로 변환한 뒤, 채널별 SEO 전략을 내재화한 프롬프트로 메타데이터를 자동 생성한다.

---

## 해결한 문제

| 기존 | 개선 |
|------|------|
| 매 업로드마다 제목 수동 작성 | 스크립트 입력 → 제목 3가지 자동 생성 |
| 채널 톤/형식을 매번 기억해서 적용 | 채널별 SEO 규칙을 프롬프트에 내재화 |
| 해시태그를 감으로 나열 | 넓은·중간·좁은 검색량 층위 자동 구성 |
| 어떤 제목이 잘 됐는지 추적 불가 | 사용한 제목 기록 저장 → 패턴 분석 가능 |

---

## 주요 기능

- **채널 선택** — 헬씨허브 / 지킴 JEEKIM 전용 설정 분리
- **3가지 입력 방식** — 영상 파일 업로드 / SRT 자막 파일 / 스크립트 직접 입력
- **자동 생성** — 제목 3가지, 썸네일 제목, 설명란, 해시태그
- **항목별 재생성** — 마음에 안 드는 항목만 따로 다시 뽑기
- **사용 제목 기록** — "이걸 사용했어요" 체크 → 채널별 누적 기록

---

## 채널별 SEO 전략

### 헬씨허브
- 제목: 제품명이 아닌 **사용 상황·문제** 중심 ("코골이 없애는 법 찾다가 발견한 밴드")
- 제목 길이: 60자 이하 (유튜브 검색 결과 잘림 방지)
- 설명란: 첫 줄에 핵심 검색 키워드 배치 (미리보기 노출 최적화)
- 해시태그: 넓은(#밴드) + 중간(#방수밴드) + 좁은(#민감피부밴드추천) 3층위 혼합

### 지킴 JEEKIM
- 제목: `핵심주제 완전정리 | 시청해야 할 이유` 파이프 구분 형식
- 잘 되는 패턴: "얼마?", "어떻게 계산?", 구체적 금액 포함
- 썸네일: 2줄 구성 — 윗줄(상황/질문) + 아랫줄(핵심 키워드)
- 해시태그: 세무/회계 주제 + 영상 핵심 주제 + 시청 대상 3분류

## 기술 스택

- HTML / CSS / JavaScript (순수 웹, 별도 설치 없음)
- OpenAI Whisper API — 영상 음성 → 텍스트 변환
- OpenAI GPT-4o-mini — 채널별 메타데이터 생성

## 사용법

1. 오른쪽 상단 ⚙ 버튼 → OpenAI API 키 입력 후 저장
2. 채널 선택 (헬씨허브 또는 지킴)
3. 영상 파일 업로드 또는 스크립트 붙여넣기
4. "메타데이터 생성하기" 클릭
5. 결과 확인 후 항목별 복사 또는 전체 파일 저장
6. 사용한 제목 옆 "이걸 사용했어요" 클릭 → 기록 저장
